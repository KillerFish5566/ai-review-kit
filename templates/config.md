## 4. 檢查命令（`kit.py checks --run` 會逐條執行）

格式：`名稱 | 命令 | required`（required 填 yes 或 no）。命令在專案根目錄用系統 shell 執行。
沒裝的工具會被記成 `skipped`，不會算通過；不要為了湊數加沒意義的命令。

```checks
name | command | required
```
